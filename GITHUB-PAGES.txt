UNBOUND — OPTION A HOMEPAGE WITH LINK PREVIEW

Main shareable address: https://samjomo.github.io/unbound/

For this existing GitHub Pages repository, upload the updated index.html AND
unbound-share.png to the repository root and commit to main. The HTML replaces
the current homepage; the PNG supplies its link-preview image.
The filename stays index.html; it does not need to match the repository name.

1. Open https://github.com/samjomo/unbound in your signed-in browser.
2. Choose Add file > Upload files.
3. Select index.html and unbound-share.png from this package, keeping those names.
4. Commit directly to main. Suggested message: Update UNBOUND carousel and sharing thumbnail.
5. Wait for the Pages deployment to complete, then refresh the main shareable address.

The existing .nojekyll and Pages settings can remain. If setting up a new copy,
upload index.html, unbound-share.png and .nojekyll to the root, then use main / (root) as the Pages
publishing source. Upload extracted files, not this ZIP.

All photographs, logo outlines, menu lettering, styles and JavaScript are embedded
in index.html. No build process, font download or other asset folder is required.
The separate unbound-share.png is required for social/link previews.
GITHUB-PAGES.txt is optional documentation; it does not need to be uploaded.

LINK PREVIEW
The static 1200 x 630 PNG uses the portrait of two women and red chair filled
with soft toys, side by side, with the Hot Coral logo. It contains no navigation or browser controls. The homepage
includes Open Graph and large-image card metadata pointing to this public image:
https://samjomo.github.io/unbound/unbound-share.png?v=2

After deployment, open that image address to confirm it loads, then share the
main homepage link. Receiving apps decide how to display and cache previews;
an existing message may keep its old preview. The thumbnail stays Hot Coral
regardless of the colour a visitor selects on the interactive website.

INCLUDED
- Twelve embedded images in six pairs, including the new roses/red drawing and
  cafe portrait/red chair pairs. The alternating timing remains unchanged.
- Option A's firm iPhone top edge and normal scrolling into the lower content.
- Side-by-side desktop photographs, equal stacked mobile photographs.
- Desktop logo width 62%; mobile 79.36%, both proportional and centred on the seam.
- Six working colour selections and the Acid Citron/Hot Coral selected-state rule.
- Condensed uppercase mobile menu lettering over a 50% black overlay.
- No bottom preview or pause controls.
- One full viewport-height #f5f4f0 section, with centred uppercase text that follows
  the selected brand colour. Mobile has three lines and about 12% side gutters.
- iPhone-specific scrolling is restricted to iPhone; other platforms use normal
  document scrolling. Added guards leave zoomed panning and editable controls alone.

VALIDATION
The user selected Option A after comparing both approaches on an iPhone 16 Pro.
The final package preserves that version's unzoomed iPhone geometry and carousel.
Desktop and narrow-screen fallback layouts, menu/colour interaction and scrolling
were checked locally. Platform and gesture guard logic was checked separately.
Not every iPhone model, landscape layout or physical Android phone was tested.
Safari's toolbar remains expanded in Option A's iPhone layout.

After uploading, give the main page one quick check on your iPhone: initial view,
scroll down and back up, and menu open/close. The original Option A test file is
still available as the comparison version.

The packaged photographs remain reference imagery for this design demo.
This package has been prepared locally; publishing requires the manual upload.
