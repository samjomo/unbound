1. Unzip unbound-github-pages.zip.
2. Upload index.html and .nojekyll directly to the top level of your repository.
   Do not upload the ZIP itself, or place index.html inside an extra folder.
   .nojekyll is a hidden, empty file; if it is not visible in your file picker,
   you can create a file named .nojekyll directly in GitHub.
3. In your repository, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the branch containing index.html (usually main), choose /(root), Save.
6. Wait for deployment, then use Visit site in the Pages settings screen.

index.html: the complete website preview.
